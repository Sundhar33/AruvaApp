# Aruva 📱

Aruva is a modern React Native mobile application designed to provide a smooth, fast, and scalable mobile experience across Android and iOS platforms.

The project focuses on clean UI/UX, reusable components, optimized performance, and professional mobile app architecture.

---

# 🚀 Features

* Cross-platform mobile app
* Beautiful and responsive UI
* Fast navigation experience
* Reusable components
* API integration
* State management support
* Clean project architecture
* Scalable codebase
* Optimized performance

---

# 🛠️ Tech Stack

## Mobile App

* React Native
* JavaScript / TypeScript
* React Navigation

* Redux Toolkit / Context API

* MongoDB / Firebase

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/aruva.git
```

Navigate to project directory:

```bash
cd aruva
```

Install dependencies:

```bash
npm install
```

Install iOS pods:

```bash
cd ios
pod install
cd ..
```

Start Metro bundler:

```bash
npm start
```

Run on Android:

```bash
npm run android
```

Run on iOS:

```bash
npm run ios
```
